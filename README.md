# Ametrine Saw

Full-colour Python 3 neon radial crystal-saw arcade for [ElbowOS](https://x.com/ElbowOS).

Aim the hub and fire a spinning saw through four counter-rotating ametrine rings.
Violet, gold, rose and teal segments shatter on contact. Clear a board and the
rings respawn faster the other way.

Left / Right (or A / D) aim. Space / W / Up fires the saw. R resets.

## Play

```
pip install -r requirements.txt
python3 ametrine_saw.py --play
```

## Record a 9:16 reel

```
python3 ametrine_saw.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
